### 1.1 FM-1 1 MB SPI NOR Flash Map, Two-Stage OTA & Anti-Brick Safety Rules

On the M-VAVE FM-1, **there is no separate factory USB-MIDI DFU partition outside the application**—USB firmware updates are served by the running firmware itself. Respecting physical flash boundaries, dual-core bus quiescing, and early boot order is mandatory to prevent soft or hard bricks:

| Physical SPI Flash Offset | Size / Mapping | Role & Hardware Safety Rule |
| :--- | :--- | :--- |
| **`0x00000 – 0x03FFF`** | `16 KB` (Boot Head / U-Boot) | **Strictly off-limits.** Stores mask-ROM / U-Boot parameters; overwriting `< 0x4000` causes a hard brick (`WL82 UBOOT1.00`) requiring external RP2040 `D+`/`D-` hardware recovery. |
| **`0x04000 – 0xDFFFF`** | `567.9 KB` `APP_SLOT` (`0x02000120` XIP) | **Application XIP region (`ruido.bin`).** Linked exclusively via `ruido_fm1.ld` starting at `_start = 0x02000120` (`04 81 80 00` jump stub). Portable `src/` emits standard `.text`/`.rodata`/`.bss` with zero custom linker section overrides (`~203 KiB` free in `APP_SLOT`). |
| **`0xE0000 – 0xE9FFF`** | `40 KB` (`0xE0000–0xE4EFF` `OTA_MAX_BYTES = 19.75 KB` + `0xE4F00–0xE9FFF` `OTA_RES`) | **Two-stage USB-MIDI OTA staging & standalone SRAM flash writer (`ota.bin` / `loader.bin` @ `0x01C0A800`).** Stage 1 verifies the incoming `.fwsc` package, stages `loader.bin` (`~10.8 KB`) into `0xE0000`, and jumps into `0x01C0A800` SRAM for Stage 2 to erase/program `0x04000–0xDFFFF` with CRC-16 readback verification without ever touching `< 0x4000`. |
| **`0xEA000 – 0xFBFFF`** | `72 KB` (`USR` NVS Area; `0xF4000–0xF9FFF` active) | **Append-only CRC-32 journaled storage (`Scenes 1–4` @ `0xF4000..0xF7FFF`, `GLOBAL CONFIG` @ `0xF8000`, `LIVE` scratchpad @ `0xF9000`).** Accessed strictly on `Core 0`'s main loop via page writes (`0` live `4 KiB` sector erases while audio is running). |
| **`0xFC000 – 0xFFFFF`** | `16 KB` (High System Tail) | **Reserved SoC / calibration tail.** Never written by application code. |

1. **Unconditional Power-On `Hold OCT-` USB Rescue Priority (`0` `.init_array` Constructors):** At power-on, `fm1_cstart()` checks whether **`OCT-` is physically held** (or `bootguard.failed >= 2`) *before* `app_main()` runs, entering a minimal single-core USB-MIDI rescue updater if triggered. To guarantee synth code can never fault before that check, `src/` and `platforms/fm1/` enforce **`-Wglobal-constructors -Wexit-time-destructors` under `-Werror`** (`0` `.init_array`/`.ctors` sections); C++ engine instances are constructed in `.pool` SRAM via placement `new` strictly *after* `Hold OCT-` rescue clears.
2. **Dual Flash JEDEC ID Support (`P25Q80` `0x856014` + `UC25HQ80` `0xB36014`):** Units shipped since Autumn 2026 populate a `UC25HQ80` (`0xB36014`) 1 MiB SPI NOR instead of Puya `P25Q80` (`0x856014`). Both the standalone Stage-2 RAM loader (`loader.bin` / `ldr_flash_known`) and the app NVS driver (`fl_jedec_ram` in `ruido.bin`) MUST contain both little-endian JEDEC IDs (`14 60 85 00` and `14 60 b3 00`, audited automatically by `build_fm1.py`) so newer units never refuse USB updates or silently drop `USR` NVS saves.
3. **`.fwsc` Fixed `588 KiB` `flash.bin` Payload & `ota.bin` (`loader.bin`) Size Ceiling:** Because `fm1pkg_make.ufw()` packs a fixed `602,112 B` (`588 KiB`) `flash.bin` container (`0x04000–0x96FFF`) plus `1,044 B` of headers/markers plus `ota.bin` (`10,769 B`), the total `ruido.fwsc` size (`613,925 B` vs `614,400 B` / `600 KiB` limit) depends on **`ota.bin` (`loader.bin`)**, NOT `ruido.bin`. Keep `loader.bin` (`-Oz` + `RUIDO_LDR_SUBSET`) strictly `<= 11,244 B` (`475 B` remaining before hitting the `600 KiB` `.fwsc` gate).
4. **Live USB-MIDI OTA (`usb.ota_req`) & U-Boot DFU (`usb.uboot_req`) Quiescing Sequence:** Before handing a live USB-MIDI OTA session (`ota_session()`, which erases `5 × 4 KiB` staging sectors at `0xE0000`) or Mask-ROM DFU jump (`0x01E00004`) to `platform_poll()`, `Core 0` **must**:
   - Flush any pending `USR` NVS journal writes while `Core 1` is still in its flash-hold loop,
   - Quiesce `Core 1` into solo fallback and halt `cpu1` hardware (`SYS_CON` `0x01EEE004`: set bit 1, clear bit 3) while disarming shared `JL_DBG` / `EMU` traps (`0x01EEE240..0x01EEF1A4`) so Stage-2 handoff or exception recovery never trips a secondary `PC_LIMIT` / `JL_DBG` fault, and
   - Drain in-flight `SPI1` LCD DMA (`lcd_sync()`) and zero `ALNK0` I2S DMA buffers (`abuf`).
5. **Core 1 `.c1_text` SRAM Isolation, NVS Flash-Hold Handshake & Boot Ordering:**
   - `Core 1` (`0x01C0E000..0x01C1FFFF`) must execute with **`0` XIP (`0x02000000+`) references**, **`0` `idle` instructions** (shared clock-gate hazard on `AC791N`), and **`0` `lockset` / `libcompiler_rt` `__sync_*` calls** (whose `cli` prologue clears `icfg` bit 9 and halts `ALNK0` / `TIMER5` IRQs).
   - Cold-boot `USR` NVS restoration and any `4 KiB` sector compaction **must** run *before* `Core 1` boots (`SYS_CON` bit 3 == 0) so `fl_cache_idle()` (`0x01EEE008`) has zero cross-core bus traffic; any live NVS page write (`fl_write` / `blob_save`) must bracket with `ruido_fm1_flash_hold_begin()` / `ruido_fm1_flash_hold_end()` (including explicit D-Cache flush on `Fm1InterCoreControl` line 0) so `Core 1` parks in SRAM until programming finishes.
6. **Vanilla `-Os` USB SIE Timing, Power-Rail Sequencing & Silicon-Lottery Auto-Heal:**
   - Keep `platform.c` and `usb.c` compiled strictly at **`-Os`** (never `-O2`/`-O3`, which alters USB SIE register access timing and causes USB babble during SysEx firmware uploads).
   - Step `VDC14` (`P3_ANA_CON6 -> 7`, `1.60 V`) then `SYSVDD` (`P3_ANA_CON9 -> 15`, `1.38 V`) up 1 step per `100 µs` before SRAM DSP load, NVS reads, and `Core 1` wake.
   - Maintain the 2-strike `bootguard` + stackless register-only `ruido_fm1_c1_boot_post` SRAM canary POST so any unit exhibiting `Core 1` bit-21 SRAM data-load glitches (`--flaky-core1`) automatically boots into Solo `Core 0` mode on Boot #2 and clears `bootguard` after 8 rendered LCD frames.
7. **Mandatory 5-Gate `fm1-emu` Verification Before Physical Flashing:** Every `.fwsc` build (`make fm1-check` / `python3 platforms/fm1/build_fm1.py`) must pass static symbol/stack/XIP audits plus all 5 `joakimeriksson/fm1-emu` hardware gates (`Timed LCD + Audio`, `Panel + SARADC + 24-PPQN MIDI`, `3-Boot USR NVS Journal`, `--flaky-core1` Fault Survival, and `Hold OCT-` USB Rescue) before `make fm1-flash` is ever run.

## 2. Dual-Core Execution Model

Ruido pins real-time DSP and UI/control scanning to separate `pi32v2` cores (`Core 1` executing out of internal `.c1_text` SRAM to prevent XIP Flash sector-erase stalls and cache contention), communicating strictly via **uncached / D-Cache-coherent lock-free triple-buffered snapshots and SPSC ring buffers**:

```text
┌─────────────────────────────────────────────┐       Uncached         ┌─────────────────────────────────────────────┐
│        CORE 0 (UI & I/O — XIP Flash)        │    Lock-Free Bus       │      CORE 1 (Hard Real-Time DSP — SRAM)     │
│                                             │ ─────────────────────> │                                             │
│ • GPIO + Settled PA7/PA8 SARADC Pressure    │                        │ • ALNK0 24 MHz Crystal DMA Master Clock     │
│ • 7x Encoder Quadrature + 3-Gear Rate Scale │    Uncached SPSC +     │ • 44.118 kHz Modulation: 8x Dual Voice LFOs │
│ • 2x 74HC595 42-Ch Gamma/ΔΣ LED Multiplexer │  LFO/Gate Telemetry    │ • 4x Oversampled Domain (176,472 Hz):       │
│ • 240x16 Ping-Pong Scanline Strip Renderer  │ <───────────────────── │   - 4x Schmitt PolyBLEP + Rail Coupling     │
│ • LCD_IDLE SPI1 DMA Transfer (~25-30 FPS)   │                        │   - 8x Nodal ZDF MS-20 (HPF -> LPF)         │
│ • Circular Scene Morph & Journaled Flash NVS│                        │ • Bus Sag + FIR + 1-LSB TPDF 16-Bit DAC Out │
└─────────────────────────────────────────────┘                        └─────────────────────────────────────────────┘
```

## 3. DSP Pipeline (`src/dsp/`)

All synthesis and filtering run inside a unified **`4x` oversampled domain (`176,472 Hz`)** using single-precision `float` before decimating once to `44,118 Hz`.

### 3.1 Schmitt-Trigger Relaxation Oscillator Model (`4x` Voices, `0.05 Hz - 20,000 Hz`, `5–95%` PWM & `0–100%` `1/f` Drift)
1. **Piecewise-Slope Band-Limited Step Generation (`5–95%` Pulse Width):** 32-bit unsigned integer (`uint32_t`) phase accumulators (`41 uHz` resolution, immune to `float32` sub-audio ULP stall down to `0.05 Hz`, bounded by `kMaxPhaseInc = 0x1F000000u` / `~21.37 kHz` with a Nyquist `minSafeDuty` guard keeping consecutive transitions `> 8` oversampled samples apart) split at `0x80000000u` with asymmetric high/low phase slopes (`incHigh = 0.5*inc / duty`, `incLow = 0.5*inc / (1 - duty)`) for exact fundamental pitch invariance across `5–95%` duty, **4-point Integrated Cubic B-Spline PolyBLEP** anti-aliasing on both rising and falling transitions (`< -109.9 dBc` alias floor `< 20 kHz` on `15%` narrow pulse), and subtle per-inverter CMOS hysteresis duty spread (`~49.2% - 50.9%`) near `50%`.
2. **RC Coupling Cap (`1.5 Hz`) & Passive Output Pole (`6.5 kHz`):** Leaky-integrator / high-pass roof sag (`~1.5 Hz` corner) preserving `-0.037 dB` seismic `10–30 Hz` sub-bass weight while stripping raw DC, paired with a passive `6.5 kHz` (`~24.5 µs`) CMOS/pot/cable RC output low-pass pole rounding `0 ns` multi-oscillator coincidence needles without dulling harmonic bite.
3. **Variable `1/f` Thermal Drift (`0–100%`):** Per-voice dual-pole (`0.996` fast + `0.9997` slow) filtered random walk normalized to `[-1, +1]` (`EngineTelemetry::voiceDriftNorm[4]`) and scaled via `fastExp2` from **`0%` `LOCKED`** (`0.00 cents` crystal phase-lock) through **`10%` default** (`~±2.2 cents` organic shimmer) up to **`100%`** (`~±120 cents` unstable transistor swarm).
4. **Two-Regime Shared Power-Rail Coupling & Starved-Rail Hard Sync (`ALGORITHM` Knob):** `0–45%` injects smooth `CD40106` crowbar pulses into a virtual `Vdd` sag bus (`25%` default chorus shimmer); `45–100%` enters **starved-CMOS rail collapse** (`[0.12x..4.5x]` phase pull + neighbor gate-load PWM duty warp + band-limited PolyBLEP hard-sync snap in the upper `14%` `Vt+` capture window).

### 3.2 Per-Oscillator MS-20 `Rev 2 -> Korg35` Dual Filter (`8x` Nodal ZDF Stages, `2 Hz - 28 kHz`) & Pre-Filter Overdrive
Each oscillator feeds an asymmetric **ESP-style pre-filter transistor overdrive (`1.0x..4.5x`, `EDIT -> LEVEL` `70–100%`) -> 2-pole Sallen-Key High-Pass Filter (`IC5`) -> 2-pole Sallen-Key Low-Pass Filter (`IC6`)** controlled on the latching **`FX`** page (`SELECT = OSC 1..4`) by `HPF` (`KNOB1`), `HP RES` (`KNOB2`), `LPF` (`KNOB3`), and `LP RES` (`KNOB4`) (`ADR-019`, `ADR-024`, `ADR-028`, `ADR-029`):
- **Capacitive Sallen-Key Nodal Topology & Clickless Linear AC-Coupling:** `HPF` injects pre-saturated input $x$ through series capacitors `C1` ($v_{C1} = y_1 - x$) and buffered `C2` ($v_{C2} = y_2 - y_1$), delivering exact `0 Hz` capacitive DC rejection (`-156 dB` input DC leak; stripping asymmetric rectifier DC from `4.5x` overdrive). When parked at `2.0 Hz` with `0%` resonance under overdrive (`> 1.0x`), `HPF` executes exact linear capacitive AC-coupling (`hpLinearAcCouple`) and bleeds residual capacitor charge smoothly (`5 ms` tau) on return to `hpLinearBypass`; any active cutoff or resonance engages full nonlinear silicon across `2 Hz – 28 kHz`. `LPF` senses `Stage 2` differential $w = y_1 - y_2$ into its `1S1588` limiter so simultaneous `HPF + LPF` self-oscillation never suffers Van der Pol bass quenching.
- **Calibrated `50%` Self-Oscillation Onset, `Rev 2 -> Korg35` Morph & Analog OTA GBW Taper (`SallenKeyMath.h`):** `0–49%` stays warmly resonant below self-oscillation; `50–60%` models singing `LM13600` OTA + `1S1588` `Rev 2` sine (`<= 0.7%` pitch tracking through `8 kHz`); `60–100%` morphs continuously into feral early `Korg35` (`k` up to `6.80`, tighter diode knees, asymmetric Stage-2 rails, and boosted `HPF -> LPF` intermodulation), while an `8.2–12.2 kHz` analog OTA gain-bandwidth taper prevents ultrasonic sweep fizz above `12 kHz`.
- **Coupled 1D Analytical Newton-Raphson Solver, Exact Nyquist Guard & Cache-Isolated Solvers:** Reducing all 3 nonlinearities per stage to a 1D scalar root with exact Nyquist Jacobian loop-gain bounding (`gHp * (kHp - 1.0) <= 0.88`, `gLp * (kLp - 0.72) <= 0.88`, guaranteeing `df >= 0.12` globally), paired 2-tick `pi32v2` ZDF secant stepping (`176.47 kHz` capacitor integration), and cache-line-isolated `64 B` `Ms20DualFilter` state (`processQuadBank4x` host SIMD parity `0.0e+00`).

### 3.3 Dual Per-Voice Analog-Modeled LFO Bank (`8x` Independent Voice LFOs: `LFO A/B OSC 1..4`, `0.01 Hz - 2,000 Hz`)
Each voice (`Osc 1..4`) owns **2 dedicated analog-modeled modulation oscillators (`LFO A` + `LFO B` = `8` total)** inside `VoiceLfoBank` (`[0..3] = LFO A`, `[4..7] = LFO B`, shared zero-`libm` `LfoMath.h`, `ADR-022`, `ADR-028`, `ADR-031`), stepped at `44,118 Hz` with `4x` linear sub-sample pitch & PWM duty interpolation (`prevOscFreqHz_`, `prevOscPw_`) into the `176,472 Hz` oscillator bank:
- **Zero-Delay `LFO B -> LFO A` Evaluation Order, 32-Bit Phase Accumulator & Capacitor Drift:** `VoiceLfoBank::stepFrame` evaluates `LFO B` (`[4..7]`) first so its live instantaneous output modulates `LFO A` (`[0..3]`) with zero 1-sample delay when `LFO B` targets `A RATE` (`±6 oct` across `[0.01 Hz, 2,000 Hz]`) or `A DEPTH` (swelling/fading `LFO A` from stillness up to crest). `uint32_t` phase accumulators (`~10.3 uHz` resolution, `100.0 s` cycles at `0.01 Hz` up to `2,000 Hz` audio-rate FM / PWM / Filter-FM / AM) initialize across all `8` phases in `45°` increments with per-LFO `1%` polystyrene timing-capacitor tolerances and slow thermal random walk.
- **Stepless Analog Waveform Morph (`SHAPE` `0..100%`):** Continuous morph across `C^2` folded polynomial `Sine` + JFET Padé crest warmth (`0.00`), MS-20 variable-symmetry `Triangle -> Sawtooth` (`0.25 -> 0.50`) with `C^1` quadratic vertex fillets and rate-adaptive flyback, vactrol-rounded `C^1` cubic `Slewed Square` (`0.75`), and non-repeating 2-segment **`C^2` Uniform Cubic B-Spline `Random` Drift** (`1.00`) packed into `8 x 30-bit` atomic `lfoDriftPacked` telemetry.
- **Clickless 10-Target Crossfade, Band-Limited PWM & Additive Dual Stacking:** Switching `KNOB 1` (`TARGET`) live crossfades per-destination weights (`~12.5 ms` tau) across **`FREQ`** (`±5 oct` audio-rate FM), **`DUTY`** (`5–95%` band-limited Schmitt PWM), **`LPF`** / **`HPF`** (`±7.5 oct` across `2 Hz – 28 kHz`), **`LP RES`** / **`HP RES`** (`0–100%` into `Korg35`), **`LEVEL`** (`0–100%` into `4.5x` MS-20 overdrive), and **`PAN`** (`L100..R100`), plus **`A RATE`** and **`A DEPTH`** exclusively on `LFO B` (`kNumLfoATargets = 8`, `kNumLfoBTargets = 10`). Pointing both `LFO A` and `LFO B` at the same destination stacks both modulations sequentially/additively.

### 3.4 Mixing, Equal-Power Pan, Master Bus Sag, DAC Safety & Polyphase Decimation
- **Stepless `C^1` Log-Potentiometer Smoothing, Vactrol Mute, Pad Pressure & Pan:** Continuous rotary controls (`freqHz`, `hpCutoffHz`, `lpCutoffHz`, `lfoRateHz`, `lfoBRateHz` in `log2(Hz)` octave space via `LogFreqSmoother`; `pulseWidth`, `drift`, `amplitude`, `pan`, `hpResonance`, `lpResonance`, `lfoShape`, `lfoDepth`, `lfoBShape`, `lfoBDepth`, `circuitCoupling`, `masterTrim` via `CriticallyDampedSmoother`) use 2-pole critically-damped cascades (`14 ms/pole`, `~28 ms` mean S-curve glide, `0%` overshoot); White Keys `1-4` (`LIVE MIXER`) drive uncapped MS-20 filter crossover/resonance or muted Buchla-style Vactrol LPG swells via `VactrolSmoother` (`4.5 ms` attack / `26.0 ms` release, `0.000 Hz` pitch shift).
- **Master Bus Sag & Post-Decimator DAC Seatbelt:** High-headroom (`0.75` linear knee, `±1.25` soft ceiling) summing bus followed by two cascaded 2x **Linear-Phase Symmetric Polyphase Half-Band FIR** stages (`> 87 dB` stopband rejection to `20 kHz`, `0°` phase dispersion) and a transparent `dacSafetyClip` guard (`100%` bit-exact linear for `|x| <= 1.15f`, smooth `±1.45f` ceiling catching FIR Gibbs overshoot on `21–28 kHz` ultrasonic edges).

## 4. Keybed `SARADC` Pressure & Scanline Strip UI (`src/ui/`)

### 4.1 Carbon-Pill Polyphonic Pressure Scanner (`Core 0`)
- Between digital matrix scans, Core 0 pulses weak GPIO pull-ups and reads the `AC791N` `SARADC` channels tied to the silicone key matrix rows, mapping nonlinear carbon-pill resistance drop through a calibrated curve + low-pass slew into continuous `[0.0f .. 1.0f]` per-key pressure values (mirrored in `platforms/sim/` via mouse drag/wheel pressure + MIDI Poly/Channel Aftertouch).
