# `src/ui/` — Scanline Oscilloscope & HUD Compositor Guidelines

`src/ui/` renders the `240x240` monochrome CRT oscilloscope and anti-aliased sans-serif HUD on `Core 0` via `240x16` `RGB565` scanline strips (`ST7789` SPI DMA ping-pong compatible).

## Layer & Hardware Rules

1. **Read-Only Consumer of `src/core/`:** `src/ui/` MUST NOT `#include` headers from `src/dsp/` or controller state-machine headers (`core/RuidoController.h`, `core/LedEngine.h`). All rendering is a pure function of `EngineControlState`, `HudState`, `EngineTelemetry`, and `ScopeRingBuffer`.
2. **Zero Full-Screen Framebuffer:** Never allocate a `240x240` pixel buffer (`115 KB`). `renderStrip(yStart, stripHeight, rgb565Out)` must produce **bit-for-bit identical** pixels across `8`-row, `16`-row, and `24`-row strip heights, using `<= 6 KB` of stack scratch (`linBuf` + `lumBuf`) passed down to sub-compositors strictly by pointer/reference.
3. **Strictly Neutral Monochrome `RGB565`:** Pack all output pixels through `packNeutralGrayRgb565` (`R5 == B5`, `G6 == (R5 << 1) | (R5 >> 4)`) with 4x4 ordered Bayer dithering—zero color tint.
4. **XIP Flash & LUT Discipline:**
   - Keep per-pixel canvas primitives (`MonoStripCanvas`) and string formatters (`HudFormat.h`) `inline` in headers so `pi32v2` Clang inlines across module boundaries without XIP call penalties.
   - Declare all shared read-only tables (`kGaussLut`, `kTonemapLut`, `kFilterSweepFreqs`) as `inline constexpr` in headers so the linker emits a single `.rodata` copy in Flash.
5. **Modularity Cap:** Keep every handwritten `.h` and `.cpp` file in `src/ui/` `<= 700` lines (exempting generated glyph tables in `FontSansAA.h`), separating trace/bloom (`ScopeTraceEngine`), filter/LFO graphs (`HudGraphs`), global/menu views (`HudGlobalViews`), and strip orchestration (`ScopeHudRenderer`).
6. **Single Source of Truth for Graph Styling (`GraphStyle.h`):** Never copy-paste viewport coordinates, baseline/horizon optical weights, column centers, or unipolar skirt/spine shaders across `HudGraphs`, `HudGlobalViews`, `HudAmpGraph`, or `HudChrome`. Import shared constants and `inline` helpers from `src/ui/GraphStyle.h`, and derive UI test sample regions from those layout constants rather than hardcoded pixel literals.
7. **Strict 3-Zone `240x240` Screen Contract:**
   - **Top Bar (`y = 0..25`):** Single authoritative status & active-control readout (`leftMain` + `leftSuffix` on the left; live value + bar **or** the 4-dot graphical `SCENE` strip on the right). **Never** duplicate Top Bar readouts in the bottom strip.
   - **Center Stage (`y = 26..187`):** Live caustic waveform, full-screen acoustic graph (`FX`, `LFO`, `LEVEL`, `PAN`, `COUPLING`, `DUTY`, `DRIFT`), `GLOBAL CONFIG` list (body & `ABOUT` left-aligned at `leftX = 16`), spatial FM-1 hardware map (`SEL`, `SAVE`, `SHIFT` with zero pill/knockout backgrounds behind labels), or the momentary Clean-Scope 4-Key `SCENE` morph screen (4 uniform LED-slit capsules + 2-line `SHIFT` guidance, zero non-Scene keyboard keys).
   - **Bottom Strip (`y = 188..239`):** Reserved strictly for `KNOB 1-4` 4-column gauges (sharing the per-oscillator `FX + LFO A/B` 3-dot modulator row across `HOME`, `LEVEL`, and stereo `PAN`, where `FX` reflects live per-oscillator filter engagement and `LFO A` / `LFO B` animate **only** when their `LfoTarget` directly modifies that screen's parameter) or calm static navigation hints / full-width horizontal pressure bar + 1-line effect descriptions (`keyPunchGuidanceDesc`) on `SEL`, `SHIFT`, and `SAVE` when `KNOB 1-4` are unmapped.
8. **HUD Header, Scene & Nomenclature Grammar (`HudHeader.cpp`, `HudKeybedView.cpp`, `HudFormat.h`):**
   - **Top-Left Primary Title (`leftMain`, `#FFFFFF` Bold):** Name the **musical or circuit parameter/domain** in full, plain English (`FREQUENCY`, `DUTY`, `DRIFT`, `FILTER`, `LEVEL`, `PAN`, `TEMPO`, `TAP TEMPO`, `LATCH`, `RAIL COUPLING`, `MASTER LEVEL`, `KEYBOARD`, `GLOBAL`, `SCENE`)—**never** the physical knob/encoder label (`ALGORITHM`, `KNOB 1`, `VOL`) and **never** cryptic abbreviations (`ALG`, `SNAP`, `PW`, `CFG`, `KEY HOLD`).
   - **Top-Left Secondary Qualifier (`leftSuffix`, `118/255` Silver Bold):** Reserved **strictly** for target or index disambiguation (` OSC 1..4`, ` 1/3..3/3`, ` 1..4`), or—when `showSceneDots` is active—replaced by the compact number-only **Horizontal Spinning Scene Disk** (`1..4` foreshortened around `sceneDialPhase` right in the `"X"` slot of **`SCENE X`**, with zero vertical tick lines between digits). Single-instance global parameters (`MASTER LEVEL`, `RAIL COUPLING`, `TEMPO`, `TAP TEMPO`, `LATCH`, `DRIVE`, `LOW PASS`, etc.) and `SAVE` / `DELETE` scene management (`SCENE` + right-aligned `SAVE` / `DELETE`) MUST leave `leftSuffix` empty (`""`).
   - **Top-Right Slot & Graphical Scene Rule:** Show live acoustic values/units (`110.04 Hz`, `120 BPM`, `25%`, `STEREO` / `MONO`, `12 dB HP -> LP`, `1 / 9`), `FINE` / `COARSE` rate badges, or the **4-dot graphical `SCENE` strip**—**never** render ASCII scene arrows (`"1 -> 2"`), `"PRESSURE MIX"`, `"EDITED"` (use strictly `ACTIVE` / `STORED` / `EMPTY`), or `"UNASSIGNED"` text on screen.
